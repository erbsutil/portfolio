Invited to lead a mini-course at UNIPAR's Academic Week for Systems Analysis and Development (TADS). The session simulated a real brief: start from scope and a prototype, decide the architecture, and start coding. We began with Astro components, then integrated React where interactivity was required so client JS stayed scoped to those islands. We pulled GitHub API data in Astro frontmatter at build time (SSG), then deployed to Netlify and checked SEO basics and PageSpeed Insights.
